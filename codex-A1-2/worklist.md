# 국내 여행 추천 프로그램 작업 리스트

기준 문서: [subject.md](./subject.md)

## 진행 원칙

- 필수 기능을 먼저 완성한 뒤 보너스 기능을 진행한다.
- 각 단계는 정상 흐름뿐 아니라 실패 흐름까지 확인해야 완료로 처리한다.
- API 키와 인증 헤더는 로그 및 결과 파일에 출력하지 않는다.
- 기본 구현 파일명은 `travel_planner.py`로 한다.

## 0. 기술 구성 결정

- [ ] 1. LLM 제공자를 선택한다: OpenAI 또는 Google Gemini
- [ ] 2. 장소 검색 제공자를 선택한다: Kakao Local 또는 Naver Local Search
- [ ] 3. 선택한 API의 환경변수 이름을 결정한다.
- [ ] 4. 선택한 API의 요청 URL, 인증 방식, 응답 구조를 확인한다.
- [ ] 5. Python 3.10 이상이 설치되어 있는지 확인한다.

완료 조건:

- 사용할 API 2개와 필요한 환경변수 목록이 확정되어 있다.

## 4. 1차 여행지 추천 구현

- [ ] 27. 입력 날짜를 포함한 LLM 프롬프트를 작성한다.
- [ ] 28. JSON 이외의 텍스트를 출력하지 않도록 프롬프트를 설계한다.
- [ ] 29. 가능하면 제공자의 구조화 출력 기능 또는 JSON 응답 모드를 사용한다.
- [ ] 30. LLM 응답을 JSON으로 파싱한다.
- [ ] 31. 다음 필수 키와 타입을 검증한다.
  - [ ] 32. `recommended_city`: string
  - [ ] 33. `weather`: string
  - [ ] 34. `events`: array of string, 1~3개
  - [ ] 35. `reason`: string
- [ ] 36. `reason`이 2~4문장 수준이 되도록 프롬프트에 명시한다.
- [ ] 37. JSON 파싱 또는 스키마 검증 실패 시 수정 프롬프트로 1회만 재요청한다.
- [ ] 38. 두 번째 시도도 실패하면 오류 목록에 기록하고 명확하게 종료한다.
- [ ] 39. 성공 시 추천 도시를 진행 로그에 출력한다.

오류 기록 예시:

```json
{
  "step": "recommendation",
  "type": "JSON_PARSE_ERROR",
  "message": "LLM response was not valid JSON"
}
```

완료 조건:

- 정상 응답이 정해진 스키마의 Python 객체로 변환된다.
- 잘못된 JSON 응답에 대한 재시도 횟수가 최대 1회로 제한된다.

## 5. 맛집 검색 구현

- [ ] 40. `recommended_city`를 장소 검색 함수의 입력으로 전달한다.
- [ ] 41. 검색어를 `추천도시 + 맛집` 형태로 구성한다.
- [ ] 42. 선택한 장소 API의 인증 헤더와 쿼리 파라미터를 구현한다.

- [ ] 44. API 응답을 공통 맛집 구조로 변환한다.
  - [ ] 45. `name`
  - [ ] 46. `address`
  - [ ] 47. `category`
  - [ ] 48. `url`
  - [ ] 49. `x`, `y` 또는 `lat`, `lng`
- [ ] 50. 좌표가 문자열로 오면 가능한 경우 숫자로 변환한다.
- [ ] 51. 검색 결과가 0건이면 빈 목록을 반환한다.
- [ ] 52. 0건 상태를 `errors` 목록에 기록한다.
- [ ] 53. 네트워크 오류를 처리한다.
- [ ] 54. `401`, `403` 인증 오류를 처리한다.
- [ ] 55. 쿼터 초과와 기타 HTTP 오류를 처리한다.
- [ ] 56. 장소 API가 실패해도 프로그램을 중단하지 않는다.
- [ ] 57. 실패 시 맛집 목록을 빈 목록으로 두고 다음 단계로 진행한다.

오류 기록 예시:

```json

  "step": "place_search",
  "type": "EMPTY_RESULT",
  "message": "No restaurants found for the recommended city"
}
```

완료 조건:

- 성공 시 공통 구조의 맛집 목록을 얻는다.
- 실패 또는 0건일 때 빈 목록과 오류 정보를 남기고 리포트 단계로 진행한다.
