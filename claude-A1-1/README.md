# 나만의 프롬프트 관리 프로그램

Python 콘솔 기반으로 나만의 프롬프트를 카테고리별로 관리하는 프로그램입니다.
프롬프트를 추가, 조회, 검색하고 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

```bash
python main.py
```

실행 후 출력되는 메뉴에서 번호를 입력해 원하는 기능을 선택합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목/내용/카테고리를 입력해 새 프롬프트를 등록합니다. |
| 2 | 프롬프트 목록 | 등록된 전체 프롬프트를 번호와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 선택한 카테고리에 속한 프롬프트만 출력합니다. |
| 4 | 프롬프트 검색 | 제목/내용에 검색어가 포함된 프롬프트를 찾습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 선택해 제목/카테고리/즐겨찾기/조회수/내용을 자세히 확인합니다 (볼 때마다 조회수가 1 증가). |
| 6 | 즐겨찾기 관리 | 번호를 선택해 즐겨찾기 상태를 추가/해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기로 등록된 프롬프트만 모아서 봅니다. |
| 8 | JSON 파일로 저장 | 현재 프롬프트 목록을 `prompts.json` 파일로 저장합니다. |
| 9 | JSON 파일에서 불러오기 | `prompts.json` 파일의 내용으로 현재 목록을 교체합니다. |
| 10 | 카테고리별 Markdown 내보내기 | 카테고리별로 묶은 프롬프트를 `exports/` 폴더에 Markdown 파일로 저장합니다. |
| 11 | 프롬프트 수정 | 번호를 선택해 제목/내용/카테고리를 수정합니다 (비워두면 기존 값 유지). |
| 12 | 프롬프트 삭제 | 번호를 선택하고 확인(y/n) 후 해당 프롬프트를 삭제합니다. |
| 13 | 조회수 Top 목록 | 조회수가 높은 순으로 정렬해 상위 5개 프롬프트를 보여줍니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타
