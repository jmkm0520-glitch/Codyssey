# Codyssey

Codyssey 과정에서 진행한 AI, 자동화, 데이터 분석 프로젝트를 한곳에서 관리하는 모노레포입니다. 각 프로젝트는 서브모듈이 아닌 일반 폴더로 포함되어 있습니다.

## 프로젝트 인덱스

| 폴더 | 주제 | 핵심 내용 |
| --- | --- | --- |
| [`Codyssey_A1-1`](./Codyssey_A1-1/) | 생성형 AI 프롬프트 관리 프로그램 | Python 콘솔에서 프롬프트 추가, 검색, 카테고리 분류 및 즐겨찾기를 관리하는 기초 프로젝트 |
| [`Codyssey_A1-2`](./Codyssey_A1-2/) | Gemini·Kakao Local 여행 계획 생성기 | 여행 날짜를 바탕으로 국내 여행지를 추천하고 맛집을 검색해 Markdown 여행 리포트를 생성하는 Python CLI |
| [`Codyssey_A1-3`](./Codyssey_A1-3/) | 냉장고 재료 기반 AI 레시피 추천 | 남은 식재료를 입력하면 Gemini가 레시피를 추천하는 반응형 웹 서비스와 Vercel 배포 프로젝트 |
| [`Codyssey_B1-1`](./Codyssey_B1-1/) | LLM 비교와 회의록 업무 자동화 | GPT, Claude, Gemini의 회의 요약 성능을 비교하고 결정 사항과 Action Item을 추출하는 프롬프트 패키지 |
| [`Codyssey_B1-2`](./Codyssey_B1-2/) | AI 기반 브랜드 광고 제작 | 스마트 전기자전거 브랜드 `VoltGo`를 기획하고 생성형 이미지, 영상, 음성 도구로 광고를 제작한 프로젝트 |
| [`Codyssey_B1-3`](./Codyssey_B1-3/) | Make·Zapier 노코드 업무 자동화 | Google Sheets의 학생 성적을 분기 처리해 이메일을 발송하고 결과를 저장하는 워크플로우 구현 및 비교 |
| [`Codyssey_M1-1`](./Codyssey_M1-1/) | 2025년 서울 기온 데이터 분석 | Meteostat 일별 관측 자료를 정제하고 기온 추세, 월별 평균, 일교차와 급격한 변화를 분석·시각화한 프로젝트 |
| [`claude-A1-1`](./claude-A1-1/) | 확장형 프롬프트 관리 프로그램 | Python 콘솔 기반 프롬프트 CRUD, 즐겨찾기, 조회수, JSON 저장·불러오기 및 Markdown 내보내기 프로젝트 |
| [`codex-A1-2`](./codex-A1-2/) | 국내 여행 추천 API 연동 설계 | LLM과 지도·장소 검색 API를 연결하는 Python 여행 추천 프로그램의 요구사항과 구현 작업 계획 |
| [`codex-B1-1`](./codex-B1-1/) | 회의비서 AI 설계와 테스트 | 회의 내용을 사실·제안·미확정 정보로 구분하고 담당자와 기한 중심의 후속 업무를 추출하는 AI 시스템 |

각 폴더의 상세한 실행 방법, 기술 구성 및 결과물은 해당 폴더의 README 또는 문서를 참고하세요.
