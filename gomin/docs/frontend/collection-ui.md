# 컬렉션 조회 화면

로그인 회원이 실제 DB에 저장한 본인의 그림일기를 `/collection`에서 조회한다.
[그림일기 MVP](../engineering/diary-mvp.md)의 이미지 생성·컬렉션 저장과 연결한다.

## 조회와 화면

- AuthGuard와 공용 세션을 재사용한다. 서버가 세션으로 소유자를 결정하며 회원 ID를 요청에 보내지 않는다.
- `GET /api/v1/collection`으로 저장 항목 목록을 한 번 조회한다. 더미 자료는 테스트에서만 사용한다.
- 최신 저장 순서로 표시하며 PC 필름은 기존 6개 단위 이동, 모바일은 2열 목록이다.
- PC·모바일 모두 고정된 감정 카테고리 버튼 없이 전체 저장 목록을 표시한다.
- 목록 로딩은 PC 필름 6칸·모바일 2열의 사진·날짜·제목 스켈레톤으로 표시한다. 정상 0건·목록 조회 실패·로딩을 구분한다. 실패하면 다시 조회할 수 있다.
- 계정 변경 시 화면 상태를 초기화하고 취소되거나 이전 계정에서 시작한 응답은 폐기한다.
- 개별 생성 이미지의 서명 URL을 그대로 사용한다. 목록은 고정 사진 칸에 `object-fit: cover`로 표시하고 모바일 상세는 원본 비율로 전체 이미지를 표시한다.
- PC·모바일 목록과 상세 이미지 오른쪽 아래에 반투명 배경의 `AI` 배지를 표시한다. 이미지 파일 자체를 수정하지 않는 화면 표시이며, 스크린리더에는 AI가 생성한 이미지임을 안내한다. 이미지 스켈레톤과 상세 이미지 오류 안내에는 배지를 표시하지 않는다.
- 합성 이미지용 확대 비율·좌표 이동이나 상세 이미지의 상단 보정은 적용하지 않는다. 상세에서는 목록 이미지 URL을 우선 재사용하며, 로딩 실패 시 상세 API의 새 이미지 URL로 교체한다. 두 URL 모두 실패하면 이미지 오류를 표시한다.

목록 저장소는 `frontend/src/lib/collection-api.ts`, 화면 상태와 탐색은 기존 `collection.ts`의 controller를 사용한다.
서버 페이지네이션이나 별도 이미지 URL 조회·갱신 타이머는 추가하지 않는다.

PC 소개 문구의 반투명 배경과 PC·모바일 목록 하단의 마무리 문구는 표시하지 않는다.

## 상세 화면

선택은 `#entry=<항목 UUID>`로 표시한다. PC는 팝업의 왼쪽에 생성 이미지, 오른쪽에 요약을 나란히 표시하고 모바일은 전체 화면 상세를 유지한다.
닫기·Escape·브라우저 뒤로가기 후 목록 위치로 복귀한다.
`GET /api/v1/collection/{entry_id}`로 본인의 저장 항목과 원본 요약을 조회한다.
제목·위로·지금의 마음·주요 고민·감정 순서를 그대로 표시한다. PC와 모바일 상세 모두 원본 비율로 전체 생성 이미지를 표시한다.
PC는 이미지와 요약을 별도 열 간격 없이 하나의 카드에 묶고, 기존 요약 색상(`#fcf9f1`)의 공통 배경·둥근 외곽·그림자를 사용한다. 카드는 기울기 없이 화면 중앙에 표시한다. 기존 가로 폭을 유지하고 세로 높이는 이미지와 요약 내용에 맞추며, 화면 높이에서 위아래 40px을 뺀 높이를 넘지 않는다.
이미지와 요약은 수직 중앙 정렬하며 긴 요약은 요약 영역 안에서 스크롤한다. 닫기 버튼은 카드 오른쪽 위에 고정한다. 상세 로딩은 목록 이미지를 즉시 표시하고 날짜·제목·요약 카드별 스켈레톤을 표시한다. 목록에 없는 항목은 이미지도 스켈레톤으로 표시한다. 이미지 URL은 상세 조회 완료만으로 교체하지 않아 브라우저 캐시를 재사용할 수 있게 한다. 닫기 버튼은 계속 사용할 수 있다. 실패 시에는 요약 영역의 안내와 닫기 버튼을 표시한다.
이미지 위에는 제목이나 메시지를 겹쳐 표시하지 않고 제목·위로 문구는 이미지 밖의 상세 영역에 유지한다.
위로 문구는 기존 저장 값도 문장별로 줄바꿈해 표시한다. DB 원문을 수정하지 않으며 좁은 화면의 자동 줄바꿈도 유지한다.
타인 또는 없는 항목은 같은 404로 처리한다. 상세 실패 시 다시 조회할 수 있다.

PC·모바일 상세 모두 ‘이 이야기 이어서 보기’를 표시하지 않는다. 대화 재개·검색·수정·삭제·공개 공유는 MVP에서 제외한다.

`frontend/public/images/collection/`의 필름·하트·새싹·구름·닫기·잎·편집 아이콘은
Figma 제공 원본 SVG다. SVG 루트 크기를 보존하고 wrapper와 transform으로 표시 크기를
맞춘다. 필름 곡선에 놓인 카드·구멍만 원본 좌표계로 배치하고 컨테이너 너비에 맞게
축소한다. 나머지 UI는 flex·grid를 사용한다.

`reference.png`와 Figma의 Photo / Reference crop 좌표는 런타임에 사용하지 않는다.
목록·모바일 상세는 API가 반환한 개별 이미지 URL을 사용하며 이미지 모델에는 `src`만 보관한다.
전체 디자인 스크린샷을 UI로 표시하지 않으며 제목·날짜·요약·버튼은 실제 요소다.
기존 공용 배경·메뉴 아이콘·온글잎 콘콘체는 재사용한다.

## 검증

기존 collection controller 테스트와 실제 API 저장소 테스트로 목록 변환·0건·실패·계정 상태 폐기를 확인한다.
프론트 변경에는 lint와 typecheck를 수행한다. 실제 제공자 생성과 운영 DB 적용은 별도 확인이 필요하다.
