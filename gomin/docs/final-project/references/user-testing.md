# 사용자 피드백과 개선 결과

## 테스트 개요

실사용자 **5명**이 [배포한 고민일기](https://www.gomin.today)를 이용하고 대면으로 피드백을 전달했다. 대화에서 요약·그림일기·컬렉션으로 이어지는 이용 흐름과 AI 응답·이미지 품질을 점검했다. 참여자는 기획 타겟과 다른 사용자들이다.

## 피드백과 개선 내용

수집한 의견 7건 중 다음 5건을 개선에 반영했다.

| ID | 사용자 피드백 | 개선 내용 |
| --- | --- | --- |
| FB-01 | 털어놓기에 들어가면 바로 입력할 수 있으면 좋겠고, 채팅창의 초록색 박스는 없으면 좋겠다. | 입력창에 자동 초점을 적용하고 포커스 테두리·입력 영역 스타일을 정리했다. |
| FB-02 | 컬렉션 상세에서 왼쪽에는 그림, 오른쪽에는 요약을 보고 싶다. | PC 상세 화면을 왼쪽 그림·오른쪽 요약으로 구성하고, 이미지 비율과 본문 스크롤을 유지했다. |
| FB-05 | 대화 내용이 늦게 나타날 때 불러오는 중인지 표시해 주면 좋겠다. | 응답 대기 표시와 대화·컬렉션 스켈레톤, 사이드 패널 스피너를 추가했다. |
| FB-06 | 다음 고민을 유도하는 대화가 불편하고 응답이 정형적으로 느껴진다. | 사용자가 주제를 바꾸기 전에는 현재 고민에 머물고, 필요한 때만 질문하도록 대화 프롬프트를 수정했다. 공감·질문·제안의 고정된 순서를 피하고 사용자의 마무리 의사를 존중하도록 했다. |
| FB-07 | 생성된 그림이 대화 내용과 무관하게 느껴진다. | 요약의 상황을 장소·행동·복색과 연결하고, 모리의 표정·몸짓으로 감정을 표현하도록 이미지 프롬프트를 수정했다. 자연 풍경을 강제하던 지시도 정리했다. |

다음 2건은 수집한 의견으로 남겼으며, 구체적인 반영 내역은 확인되지 않았다.

| ID | 사용자 피드백 |
| --- | --- |
| FB-03 | 헤더의 ‘홈’보다 ‘털어놓기’처럼 목적을 알 수 있는 이름이 좋겠다. |
| FB-04 | 키보드로 더 편하게 이용할 수 있으면 좋겠다. |

피드백을 통해 입력을 시작하고 결과를 읽는 과정, 기다리는 동안의 안내를 개선했다. AI 결과는 사용자가 원하는 시점에 대화를 마무리하고, 자신의 이야기를 떠올릴 수 있는 그림을 만드는 데 초점을 맞췄다. 위 내용은 반영한 수정 내역이며, 개선 후 만족도나 품질을 별도로 측정한 결과는 아니다.
