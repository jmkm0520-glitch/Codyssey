## 기획 배경

고민을 누군가에게 이야기하고 싶어도 어디서부터 꺼내야 할지 막막할 때가 있다. 혼자 일기를 쓰려면 복잡한 마음을 문장으로 정리해야 하고, 대화로 털어놓은 이야기는 나중에 다시 살펴보기 어렵다. 고민일기는 마음을 표현하는 일과 기록으로 남기는 일을 하나의 흐름으로 연결하기 위해 기획했다.

사용자는 AI 친구 모리에게 편하게 이야기를 건네고, 대화가 끝나면 자신의 고민과 감정을 요약으로 확인한다. 이어 모리가 등장하는 그림과 짧은 위로 문구로 그날의 마음을 남긴다. 저장한 기록은 필름 형태의 컬렉션에서 다시 살펴볼 수 있다.

친근한 캐릭터가 사용자의 감정을 표정과 행동으로 표현하도록 하고, PC와 모바일에서 이용할 수 있는 반응형 웹으로 구성했다. 대화로 시작해 요약과 그림일기를 거쳐 컬렉션에 남기는 경험을 서비스의 중심에 두었다.

## 해결하려는 문제

**자신의 고민을 표현하고 싶지만, 혼자 글로 정리하기 어렵고 긴 대화를 다시 읽는 일도 부담스러운 사용자에게 자연스럽게 고민을 꺼내도록 유도하고 기록을 남길 방법을 제공한다.**

다음 세 가지 불편에 주목했다.

| 사용자가 겪을 수 있는 상황 | 기획에서 풀려는 문제 |
| --- | --- |
| 마음은 복잡하지만 일기의 첫 문장을 쓰기 어렵다. | 정리된 글을 요구하지 않고 짧은 대화로 이야기를 시작하도록 한다. |
| 이야기를 나눴지만 무엇이 고민이었는지 한눈에 잡히지 않는다. | 지금의 마음·주요 고민·감정 태그로 대화를 정리한다. |
| 긴 기록을 다시 읽기보다 그날의 마음을 간단히 떠올리고 싶다. | 그림과 짧은 문구를 함께 남기고 컬렉션에서 다시 보도록 한다. |

## 대상 사용자와 이용 상황

1차 대상은 심리 상담을 받고 싶거나 받고 있는 만 10~24세 청소년·청년이다. 학업과 관계, 진로 등 일상의 고민을 표현하고 정리하는 경험에 집중한다.

학업이나 진로, 친구·가족과의 관계가 마음에 남은 날을 생각했다. 누군가에게 말하고 싶지만 어디서부터 시작할지 모르거나, 이야기를 나눈 뒤 자신의 마음을 기록해 두고 싶은 순간에 고민일기를 이용하도록 기획했다. 사용자는 해결책을 바로 구하지 않고 이야기만 나눌 수도 있다.

## 서비스 가치와 해결 방식

### 1. 고민을 유도한다

사용자는 잘 쓴 일기 대신 짧은 메시지를 보낸다. 모리는 앞선 맥락을 살피고 현재 고민에 머물며 응답한다. 질문은 생각 정리에 필요할 때 건네고, 사용자가 마무리하려 하면 대화를 더 이어가도록 유도하지 않는다.

### 2. 마음을 정리한다

대화를 마무리하면 서버에 저장된 원문을 바탕으로 요약한다. 사용자는 지금의 마음, 주요 고민, 감정 태그를 확인하고 더 할 말이 있으면 같은 대화로 돌아간다. 그림으로 남길 내용은 사용자가 요약을 확인한 뒤 확정한다.

### 3. 한 장면으로 남긴다

확정한 요약으로 제목과 위로 문구, 그림의 장면을 구성한다. 모리의 표정과 행동에 고민의 상황과 감정을 담고, 완성된 결과를 컬렉션에 모은다. 그림은 대화를 시각적으로 재구성한 결과이며, 그림 속 묘사를 사용자의 실제 경험으로 단정하지 않는다.

일반적인 텍스트 일기와 비교하면 글을 완성하기 전에도 대화로 시작할 수 있다는 점에, 대화형 서비스와 비교하면 대화 뒤에 요약·그림·컬렉션이 이어진다는 점에 초점을 맞췄다. 이러한 방식이 기록의 부담을 줄이고 다시 보고 싶은 경험을 만드는지는 사용자 테스트로 확인한다.

## AI 활용 방식과 기술적 접근

필수 요구사항의 기술 중 **멀티모달 AI**와 **Long-term Memory**를 선택했다. 멀티모달 AI는 텍스트 프롬프트와 모리 참조 이미지를 함께 입력해 그림일기를 생성하는 데 활용한다. Long-term Memory는 대화 내용을 DB에 저장하고, 이후 같은 대화를 다시 불러왔을 때 이전 발화를 AI에 전달해 맥락을 이어가는 방식으로 적용한다.

AI는 대화·요약·그림 구성·이미지 생성에 사용한다. 같은 대화의 원문을 바탕으로 모리가 응답하고 요약한다. 확정한 요약에서 제목·위로·장면 설명을 만든 뒤, 장면 설명과 모리 참조 이미지를 이미지 생성 모델에 전달한다.

프론트엔드는 Next.js·React·TypeScript, 서버는 Python·FastAPI·Uvicorn으로 구성했다. 서버가 외부 AI 호출, 사용자 권한 확인, Supabase DB·Storage 저장을 담당한다. AI 응답의 구조와 실패 여부를 검사하고, 실패한 작업을 완료 결과로 표시하지 않도록 처리한다.

이 구성은 사용자마다 다른 고민을 해석하고 그에 맞는 기록을 만들기 위해 선택했다. 텍스트와 이미지를 함께 처리하고, 대화 요약부터 그림 구성·생성·저장까지 여러 단계를 연결했다.

## MVP 범위

| 포함 범위 | 사용자에게 제공하는 기능 |
| --- | --- |
| 회원·인증 | 회원가입·로그인과 본인 기록 접근 |
| 털어놓기 | 모리와의 대화, 저장된 대화 조회·맥락 유지 |
| 대화 정리 | 요약 확인·확정, 같은 대화 재개·재요약 |
| 그림일기 | 제목·위로·이미지 생성, 같은 요약으로 다른 그림 생성 |
| 컬렉션 | 결과 저장, 본인 목록·상세 조회 |
| 공통 사용성 | PC·모바일 화면, 단계별 대기·실패 안내 |

이번 핵심 범위에서 파일·사진·음성 첨부, 요약 직접 편집, 컬렉션 기록의 검색·수정·삭제·공개 공유는 제외한다.
