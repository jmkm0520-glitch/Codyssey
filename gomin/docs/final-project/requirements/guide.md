# 가이드 요구사항

## 요구사항

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| GUIDE-001 | 접근 | 가이드 페이지 조회 | 사용자는 로그인 여부와 관계없이 가이드 페이지에 접근할 수 있다. |
| GUIDE-002 | 콘텐츠 | 서비스 이용 과정 안내 | 가이드 페이지에서 이야기를 들려주세요 → 마음을 함께 정리해요 → 한 장면으로 남겨요 → 컬렉션에 모아봐요 순서로 이용 과정을 표시한다. 각 항목은 이미지, 제목, 설명으로 구성하며 별도의 클릭 또는 터치 동작은 제공하지 않는다. |
| GUIDE-003 | 이동 | 털어놓기 | 로그인 사용자가 털어놓기 버튼을 선택하면 AI 대화하기 페이지로 이동한다. |
| GUIDE-004 | 권한 | 털어놓기 접근 제한 | 비로그인 사용자는 털어놓기 기능을 사용할 수 없으며 AI 대화하기 페이지로 직접 진입할 수 없다. |
| GUIDE-005 | 내비게이션 | 하단 내비게이션 | 홈, 가이드, 컬렉션 메뉴를 제공하며 각 메뉴 선택 시 해당 페이지로 이동한다. |
| GUIDE-006 | 내비게이션 | 현재 메뉴 표시 | 가이드 페이지에서는 하단 내비게이션의 가이드 메뉴를 활성 상태로 표시한다. |
| GUIDE-007 | 화면 | 반응형 화면 | 가이드 페이지는 모바일·PC 환경을 지원하며 각 화면 크기에 맞는 디자인을 적용한다. |
