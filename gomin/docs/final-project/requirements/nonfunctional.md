# 비기능 요구사항

## 서비스 품질 기준

| 영역 | 요구사항 | 검증 기준 |
| --- | --- | --- |
| 접근 제어 | 목록·상세·이미지·대화에 본인만 접근하도록 한다. | 다른 회원의 식별자나 주소로 내용을 조회하거나 이미지 접근 주소를 발급받을 수 없다. |
| 접근성 | 주요 입력·이동·닫기 동작을 키보드로 이용할 수 있도록 한다. | 로그인·홈 이동·대화 입력이 가능하고, 사이드바와 상세 화면을 Escape로 닫을 수 있다. |
| 텍스트 | 그림과 함께 제목·날짜·요약을 읽을 수 있도록 한다. | 저장한 결과와 상세 화면의 제목·날짜·원본 요약이 일치한다. |
| 안정성 | 같은 결과를 반복 저장해도 컬렉션 항목이 중복 생성되지 않도록 한다. | 연속 클릭·동시 요청·응답 유실 후 재요청에도 기존 항목과 최초 저장 시각을 유지한다. |
