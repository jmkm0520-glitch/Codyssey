# 회원·인증 요구사항

## 회원가입

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| SIGNUP-001 | 입력 | 가입 정보 입력 | 일반 이메일 가입은 이름·이메일·비밀번호 입력, 이메일 소유 인증, 필수 약관 동의가 필요하다. |
| SIGNUP-002 | 검증 | 가입 조건 검증 및 안내 | 사용자는 가입 조건을 충족하지 못한 항목과 수정이 필요한 내용을 안내받아야 한다. |
| SIGNUP-003 | 예외 | 기존 계정 가입 제한 | 이미 가입된 이메일에는 가입용 인증번호를 보내지 않고 로그인을 안내한다. |
| SIGNUP-004 | 완료 | 회원 생성 후 로그인 및 홈 이동 | 이메일 가입과 Google 가입 모두 가입 완료 즉시 로그인 상태로 전환하여 홈으로 이동하며 별도 로그인 절차를 다시 요구하지 않는다. |

## 이메일 인증

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| EMAIL-001 | 인증 | 인증번호 발급 및 검증 | 이메일로 받은 숫자 6자리 인증번호를 입력해 이메일 소유를 확인한다. 인증번호는 발송 접수 후 3분 동안 유효하다. |
| EMAIL-002 | 발송 | 인증 메일 발송 | 인증 메일은 서버의 메일 발송 모듈을 통해 보낸다. |
| EMAIL-006 | 예외 | 인증 오류 안내 | 인증번호 불일치와 만료를 구분해 안내한다. 무효화된 번호는 다시 사용할 수 없다. |
| EMAIL-007 | 예외 | 메일 발송 실패 안내 | 메일 발송에 실패하면 오류를 안내하고 새 인증번호를 요청할 수 있도록 한다. |
| EMAIL-009 | 유효성 | 인증 성공 내역의 유효기간 | 인증에 사용한 번호는 다시 쓸 수 없다. 인증 성공 후 30분 안에 가입을 완료해야 하며, 시간이 지나면 다시 인증한다. |
| EMAIL-010 | 입력 | 인증된 이메일 변경 제한 | 인증 완료 후 이메일 입력란을 수정할 수 없게 한다. 다른 이메일을 사용하려면 인증 단계부터 다시 시작해야 한다. |
| EMAIL-011 | 완료 | 인증 내역 사용 완료 | 가입을 완료하면 해당 인증 내역을 사용 완료 처리해 다시 사용할 수 없도록 한다. |

## 구글 가입·로그인·계정 연결

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| GOOGLE-001 | 지원 | 구글 로그인 제공 | 소셜 로그인은 Google 로그인만 제공한다. |
| GOOGLE-002 | 가입 | Google 프로필로 가입 | 최초 가입 시 Google의 이름·이메일을 사용하고 별도 비밀번호 입력과 자체 이메일 인증은 생략한다. 이름을 확인하고 필수 약관에 동의하면 가입을 완료한다. |
| GOOGLE-003 | 입력 | 프로필 이름 보완 | Google 프로필 이름이 없거나 이름 규칙에 맞지 않으면 가입 화면에서 입력·수정하도록 한다. |
| GOOGLE-004 | 연결 | 같은 이메일의 계정 연결 | 검증된 Google 이메일이 기존 회원 이메일과 같으면 기존 계정에 연결해 로그인한다. 새 계정을 만들지 않고 기존 대화·그림일기·컬렉션을 유지한다. |
| GOOGLE-005 | 유지 | 기존 정보와 로그인 방식 유지 | Google 계정을 연결해도 기존 회원 이름·비밀번호·기록을 유지한다. 기존 이메일·비밀번호 로그인도 계속 사용할 수 있다. |
| GOOGLE-006 | 예외 | 인증 취소·실패 안내 | 인증을 취소하면 시작 화면으로 돌아간다. 실패하면 오류와 재시도를 안내하고 가입·연결을 완료하지 않는다. |

## 로그인·로그인 유지

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| LOGIN-001 | 완료 | 로그인 후 화면 이동 | 로그인하면 원래 접근하려던 보호 화면으로 돌아간다. 별도 목적지가 없으면 홈으로 이동한다. |
| LOGIN-002 | 예외 | 로그인 실패 안내 | 이메일 미가입과 비밀번호 불일치를 구분하지 않고 “이메일 또는 비밀번호를 확인해 주세요.”로 동일하게 안내한다. |
| LOGIN-003 | 유지 | 로그인 유지 | 브라우저를 다시 열어도 유효한 세션이면 로그인 상태를 유지한다. 현재 사용자 확인 시 유효기간을 7일로 갱신하며 만료된 세션은 다시 사용하지 않는다. |
| LOGIN-004 | 갱신 | 로그인 상태 자동 갱신 | 서비스 이용 중 인증 갱신이 필요하면 시스템이 사용자 입력 없이 갱신하여 로그인 상태를 유지한다. |
| LOGIN-005 | 만료 | 인증 만료 안내 | 만료됐거나 로그아웃으로 종료된 세션은 갱신하지 않는다. 보호 화면에 접근하면 다시 로그인하도록 안내한다. |

## 로그아웃

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| LOGOUT-001 | 종료 | 현재 기기 로그아웃 | 현재 기기의 로그인 상태를 종료하고 가이드로 이동한다. 다른 기기의 세션은 유지한다. |

## 공통 규칙

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| MEMBER-001 | 이름 | 이름 입력 및 길이 검증 | 이메일 가입과 Google 가입 모두 항목명을 이름으로 표시한다. 이름은 앞뒤 공백 제거 후 1~30자로 제한하고 한글·영문 등 문자와 이름 사이 공백을 허용하며 중복을 허용한다. |
| MEMBER-002 | 이름 | 공백 이름 제한 및 실명인증 범위 | 이름에 대한 실명인증은 수행하지 않으며, 공백만 입력한 이름은 허용하지 않는다. |
| MEMBER-003 | 이메일 | 이메일 정규화 및 형식 검증 | 이메일은 앞뒤 공백을 제거하고 형식이 올바른지 검증한다. |
| MEMBER-005 | 비밀번호 | 비밀번호 길이 검증 | 비밀번호는 최소 8자로 입력한다. 비밀번호 확인 값이 일치하지 않으면 가입할 수 없다. |
| MEMBER-008 | 비밀번호 | 비밀번호 확인 일치 검증 | 일반 가입에서 비밀번호 확인을 입력받고 두 값이 일치해야 완료할 수 있다. |
| MEMBER-009 | 비밀번호 | 비밀번호 숨김 및 보기 | 비밀번호는 기본적으로 가려 표시하고 사용자가 보기를 선택하면 입력값을 확인할 수 있다. |
| MEMBER-010 | 저장 | 비밀번호 단방향 해시 저장 | 비밀번호는 평문으로 저장하지 않고 단방향 해시로 저장한다. |
| MEMBER-011 | 약관 | 필수 약관 개별 동의 | 이메일 가입과 Google 가입 모두 이용약관과 개인정보 수집·이용 동의를 각각 필수로 받는다. 하나라도 동의하지 않으면 가입할 수 없으며 선택 동의 항목은 두지 않는다. |
| MEMBER-012 | 약관 | 약관 전문 열람 및 동의 이력 저장 | 가입 화면에서 각 약관 전문을 열람할 수 있다. 이용약관과 개인정보 수집·이용 동의 전문 및 버전은 우선 프론트엔드에 정적으로 관리하며, 가입 완료 시 동의한 각 약관 버전과 동의 시각은 서버에 저장한다. |
| MEMBER-013 | 접근 | 비회원 접근 범위 | 비회원은 가이드를 볼 수 있다. 홈·털어놓기·컬렉션·설정은 로그인이 필요하다. |
| MEMBER-014 | 중복 처리 | 회원 처리 요청 중복 방지 | 가입·인증번호 발송 중 같은 요청이 중복 실행되지 않도록 한다. |
