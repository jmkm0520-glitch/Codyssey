# 털어놓기 요구사항

## 접근과 대화하기

| ID | 기능 | 요구사항 | 관련 Jira |
| --- | --- | --- | --- |
| TALK-001 | 접근 제어 | 로그인 사용자만 대화·요약 기능을 이용한다. 서버는 세션 회원을 기준으로 본인의 대화·메시지·요약만 조회·변경하도록 검사한다. 화면과 서버에서 로그인 상태를 확인한다. | GOMIN-66 |
| TALK-002 | 대화 화면 | 안내 문구, 사용자·모리 대화 영역, 메시지 입력창, 전송 버튼과 현재 글자 수를 제공한다. PC·모바일에서 같은 기능을 제공한다. | GOMIN-66·68 |
| TALK-003 | 메시지 전송 | 유효한 입력을 전송하면 사용자 메시지를 저장·표시하고 모리 응답을 요청한다. 메시지별 발화자·본문·저장 시각과 대화 내 순서를 구분한다. | GOMIN-66 |
| TALK-004 | AI 응답 | 모리는 해당 대화의 이전 원문을 맥락으로 사용해 공감·위로하고 고민·감정을 구체화한다. 사용자와 모리의 메시지를 구분된 말풍선으로 표시하고 각 메시지의 시간을 표시한다. | GOMIN-66 |
| TALK-015 | 입력 검증 | 빈 문자열 또는 공백·줄바꿈만 있는 입력은 전송하지 않는다. 사용자 메시지는 공백·줄바꿈을 포함해 최대 100자이며 글자 수를 표시한다. 100자를 초과한 메시지는 전송하지 않는다. | GOMIN-67·68 |
| TALK-019 | 기기별 입력 | PC는 Enter로 전송하고 Shift+Enter로 줄바꿈한다. 모바일은 Enter로 줄바꿈하고 전송 버튼으로 전송한다. 한글 등 입력 조합 중 Enter는 조합 확정으로 처리해 의도하지 않은 전송을 막는다. | GOMIN-68 |
| TALK-020 | 응답 대기 중 입력 | 모리 응답 대기 중에도 입력·수정은 가능하지만 추가 전송은 제한한다. 응답 완료 후 작성 중인 입력을 유지하고, 사용자가 직접 전송할 때만 전송한다. 작성 중인 내용을 자동 전송하지 않는다. | GOMIN-68 |
| TALK-021 | 첨부 제외 | MVP에서 파일·사진·음성 첨부를 지원하지 않고 첨부 아이콘도 숨긴다. 이미지 생성 기능은 후속 담당 영역의 별도 기능이다. | GOMIN-68 |
| TALK-022 | 저장된 대화 복원 | 같은 계정으로 해당 대화를 다시 열면 서버에 저장된 사용자·모리 메시지를 원래 순서와 시간으로 복원한다. 전송 전 입력 초안은 새로고침·재접속 후 복원하지 않는다. | GOMIN-68 |

## 대화 마무리·요약

| ID | 기능 | 요구사항 | 관련 Jira |
| --- | --- | --- | --- |
| TALK-005 | 마무리 활성화 | 첫 사용자 메시지가 서버에 저장된 시점부터 대화 마무리하기를 활성화한다. 단순 입력이나 저장 전 화면 표시만으로 활성화하지 않는다. 대화 횟수·AI 판단을 추가 활성화 조건으로 두지 않는다. 마무리 화면에서도 메시지 입력창을 제공한다. | GOMIN-72·77 |
| TALK-006 | 요약 생성 | 대화 마무리하기 선택 시 현재까지 서버에 저장된 해당 대화를 바탕으로 요약을 생성한다. 저장하지 않은 입력 초안이나 다른 대화의 내용을 요약에 포함하지 않는다. 처리 중 상태와 성공·실패를 구분한다. | GOMIN-72 |
| TALK-007 | 요약 조회 | 지금의 마음은 문장, 주요 고민은 목록, 자주 느끼는 감정은 태그로 표시한다. 예시 문구·감정·날짜를 사용자 결과로 사용하지 않는다. | GOMIN-72·77 |
| TALK-008 | 요약 확정·전달 | 이 내용으로 정리하기를 선택하면 현재 표시된 해당 대화의 요약을 확정한다. 확정 요약의 식별자와 내용을 후속 이미지 생성 기능에서 참조할 수 있도록 전달한다. 이미지가 아직 생성되지 않았다면 이미지·일기·컬렉션 저장 완료로 표시하지 않는다. | GOMIN-72, 후속 GOMIN-73 |
| TALK-009 | 대화 재개·재요약 | 다시 이야기하기를 선택하면 기존 대화와 맥락을 유지한 채 대화 화면으로 돌아간다. 추가 대화 후 다시 마무리하면 추가 내용을 반영한 새 요약을 생성한다. 수정은 대화 재개·재요약을 통한 수정이며 요약 문구·감정 태그 직접 편집은 제공하지 않는다. | GOMIN-72·78 |
| TALK-014 | PC·모바일 | PC·모바일 모두 대화 → 마무리 → 요약 → 확정 또는 대화 재개 흐름을 제공한다. 기기별 배치·입력 동작을 적용하고 모바일의 추가 메뉴를 임의로 넣지 않는다. | GOMIN-66·68·72 |

## 로딩·오류

| ID | 기능 | 요구사항 | 관련 Jira |
| --- | --- | --- | --- |
| TALK-016 | 처리 중 표시 | AI 응답·요약 처리 중임을 사용자가 구분할 수 있게 표시한다. 대화 응답 대기 중 추가 전송 제한은 TALK-020을 따른다. 이미지·저장 단계의 표시와 실행 제어는 해당 후속 담당이 구현한다. | GOMIN-68·75 |
| TALK-017 | 오류·보류 안내 | 대화 응답 실패와 요약 실패를 구분해 오류 및 보류 상태를 안내한다. 실패를 정상 응답·완성 요약·확정 성공으로 표시하지 않는다. MVP에는 실패한 작업의 재시도 버튼·자동 재시도·별도 복구 기능을 추가하지 않는다. | GOMIN-75·83·84·85 |
