# 컬렉션 요구사항

## 요구사항

| ID | 구분 | 기능 | 요구사항 |
| --- | --- | --- | --- |
| COLLECTION-001 | 접근 | 컬렉션 로그인 접근 | 컬렉션은 로그인한 회원만 이용할 수 있다. 비회원이 컬렉션에 접근하면 로그인 화면으로 안내하고, 로그인 성공 후 컬렉션으로 돌아온다. |
| COLLECTION-002 | 저장 | 완료된 고민 기록 저장 | 사용자가 털어놓기 대화를 마무리하고 고민 정리와 이미지 생성이 완료되면 해당 기록을 컬렉션에 저장하여 이후 다시 조회할 수 있다. |
| COLLECTION-003 | 목록 | 생성 이미지 기반 기록 표시 | 컬렉션에는 저장된 고민 기록을 생성 이미지 중심으로 표시하며 사용자가 각 기록을 구분하고 선택할 수 있다. |
| COLLECTION-004 | PC 화면 | 필름 형태 컬렉션 표시 | PC에서는 책상 배경 위에 하나로 연결된 긴 필름 형태로 컬렉션을 표시하고 한 화면에서 약 6개의 이미지 프레임이 정면으로 보이도록 한다. |
| COLLECTION-005 | PC 탐색 | 좌우 컬렉션 이동 | PC에서 현재 화면에 표시되지 않은 기록이 있으면 필름 양옆의 좌·우 이동 버튼을 통해 이전·다음 기록을 탐색할 수 있다. |
| COLLECTION-006 | 상세 | 기록 선택 및 고민 요약 조회 | 사용자가 컬렉션의 이미지를 선택하면 해당 이미지와 연결된 그날의 고민 요약 내용을 조회할 수 있다. |
| COLLECTION-007 | PC 상세 | 그림·요약 통합 모달 | PC에서 기록을 선택하면 왼쪽 그림과 오른쪽 요약을 하나의 모달로 보여 준다. 원본 그림 비율과 긴 요약의 스크롤을 유지한다. |
| COLLECTION-008 | PC 상세 | 팝업 닫기 | PC 상세 팝업을 닫으면 컬렉션 화면으로 돌아가며 사용자가 보던 컬렉션 위치를 유지한다. |
| COLLECTION-009 | 모바일 상세 | 전체 화면 상세 전환 | 모바일에서 컬렉션 이미지를 선택하면 모달이 아닌 전체 화면 상세 화면으로 전환하여 해당 기록의 고민 요약을 표시한다. |
| COLLECTION-010 | 모바일 상세 | 상세 화면 뒤로가기 | 모바일 상세 화면의 왼쪽 상단에 아이콘 형태의 뒤로가기 버튼을 제공하며 ‘뒤로가기’ 텍스트는 표시하지 않는다. 선택하면 컬렉션 화면으로 돌아간다. |
| COLLECTION-011 | 내비게이션 | 컬렉션 현재 위치 표시 | PC에서는 상단 내비게이션, 모바일에서는 하단 내비게이션의 컬렉션 항목을 활성 상태로 표시하여 현재 위치를 알 수 있게 한다. |
| COLLECTION-012 | 빈 상태 | 저장 기록 없음 안내 | 저장한 기록이 없으면 빈 상태를 안내하고 털어놓기를 시작할 수 있도록 연결한다. |
| COLLECTION-013 | 데이터 | 회원별 컬렉션 분리 | 컬렉션에는 현재 로그인한 회원의 고민 기록만 표시하며 다른 회원의 기록을 조회할 수 없어야 한다. |
