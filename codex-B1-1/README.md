# codex-B1-1

GenAI 기초 1 「LLM 기반 업무 자동화」 과제로 제작한 **회의비서 AI** 프로젝트입니다.

회의 원문을 바탕으로 확정 사항, 제안·요청 사항, 후속 업무, 미확정 사항과 리스크를 구분해 요약하도록 프롬프트를 단계적으로 개선하고, 여러 LLM의 결과를 비교했습니다.

- ChatGPT, Claude, Gemini 회의 요약 결과 비교
- 회의록 요약 프롬프트의 단계별 개선 과정
- 사실과 제안·잠정·미확정 정보를 구분하는 규칙 설계
- 담당자·기한 중심의 후속 업무 추출
- 회의비서 AI 제작 및 테스트 결과
